# nlohmann/json

This project vendors the official single-header distribution of **nlohmann/json 3.11.3**.

- Header: `single_include/nlohmann/json.hpp`
- Upstream: <https://github.com/nlohmann/json>
- License: `LICENSE.MIT`

The version is pinned in-tree so configuring the game does not require a package manager or network access.
